Individual WebP crops from the mascot artwork supplied by the user in this conversation.
No third-party or generated replacement artwork is used.

- `remeong-*`: dog expression/pose sheet (18 poses) and separately supplied dog portrait.
  The sheet's original “봄이” label is intentionally presented as “리멍이”, as approved.

  enclosed facial/body colors are preserved.

The interface currently uses the portrait, greeting, basic, curious, cheer, rest,
sleep, walk, run, and empty states. Remaining crops are available for later use.
