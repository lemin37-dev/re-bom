## 4. 01 입양 절차 안내

### 4.1 국가동물보호정보시스템 입양 안내 (참고만 함, 실측)

| 구역 | 내용 요약 |
|---|---|
| 입양자 준수사항 | 9개 항목: 먹이·물·운동·휴식 보장, 아플 때 치료, 학대 금지, 식용·번식·판매 금지, 사고 책임, 유기·파양 금지, 내장형 동물등록, 사후관리 협조, 중성화 |
| 입양전 교육 안내 | 동물사랑배움터 온라인 교육 2개 (반려견, 반려묘) |
| 입양 자료 | 한글 파일 2개: 입양 설문지, 입양 신청서 (동물보호센터 운영 지침 별지) |

- 원문 문장·표·파일은 옮기지 않습니다. 파일도 우리 서버에 올리지 않습니다.
- 동물보호법에 있는 의무(동물등록 등)는 법령 내용이라 우리 말로 안내합니다.

### 4.2 단계별로 붙일 안내 (모두 우리 말로 새로 씀, 링크 없음)

| 단계 | 지금 | 붙일 안내 |
|---|---|---|
| 1 공고 확인 | 공고 10일 안내 | (그대로) |
| 2 전화 상담 후 방문 | 상담·방문 안내 | "보호센터에 따라 입양 설문지와 신청서를 써요. 방문 전에 어떤 서류가 필요한지 물어보세요." + **방문 전 체크리스트로 이동** 버튼 (`#visit-checklist`) |
| 3 입양 전 교육 | 동물사랑배움터 안내 | "동물사랑배움터 누리집의 온라인 교육에서 '반려견 입양 전 교육' 또는 '반려묘 입양 전 교육'을 찾아 들어요. 지역에 따라 입양비 지원을 받을 때 수료증이 필요해요." |
| 4 입양 | 서류 작성 후 데려옴 | **"입양할 때 약속하는 것"** 4줄 (아래) |
| 5 동물등록 | 2개월 이상 개 30일 안 | (그대로) + "등록 방식(내장형 등)은 보호센터·지자체에 확인해 주세요." |
| 6 입양비 지원 신청 | 영수증 청구 | **우리 지역 지원으로 이동** 버튼 (`#support`, 화면 안 이동) |

"입양할 때 약속하는 것" 문안 (우리 말로 새로 씀):
- 끝까지 함께해요. 버리거나 다시 돌려보내지 않아요.
- 잘 먹고, 쉬고, 움직일 수 있게 돌보고, 아프면 바로 치료해요.
- 동물등록을 하고, 보호센터가 연락하면 지내는 모습을 알려 줘요.
- 번식·판매 같은 다른 목적으로 데려오지 않아요.

화면 아래 작은 글씨:
- "입양 절차와 준수사항은 국가동물보호정보시스템의 입양 안내를 참고해 정리했어요. 자세한 내용은 국가동물보호정보시스템 누리집의 '입양 안내'에서 볼 수 있어요." (링크 없음)

확인한 점:
- 국가 페이지의 준수사항은 "3개월 이상 개는 내장형 등록"이라고 적혀 있습니다.
- 현행 동물보호법은 2개월 이상 개가 등록 대상입니다. 그래서 5단계는 2개월을 유지합니다.

### 5.3 한계

- **등록 건수가 적습니다.**
  - 미리 조사한 구리시, 부산시 펫보험은 이 API에서 나오지 않았습니다.
  - 검색 결과에 보이는 서울시 동물보험 지원과 경기도 펫보험 지원 같은 시·도 사업도 나오지 않았습니다.
  - 전국에서 몇 곳이 운영하는지는 확인하지 못했습니다.
- **금액이 지역마다 다릅니다.** 실측은 15만~25만원이고, "부담비용의 60%" 같은 조건도 있습니다.
- **예산이 떨어져도 데이터에는 나오지 않습니다.**
- **조건이 '어느 보호소에서 입양했는지'에 걸려 있습니다.** 8건 모두 "구(시·도) 지정 보호센터에서 입양"이 조건입니다.

점검 흐름:

```
(나) 예산이 잡힌 지자체 ─┐
(다) 조례가 있는 지자체 ─┼─▶ 5.1 API에 없는 지자체 목록 ─▶ 운영팀이 해당 지자체 공고 확인 ─▶ (가) 보강 표
                        │
5.1 API 8건 ────────────┘
```

- (나)·(다)는 "이 지자체에 사업이 있을 수 있다"는 신호입니다. 금액·조건은 들어 있지 않아 **화면에 직접 쓰지 않습니다.**
- 보강 표(가)를 화면에 쓸 때는 출처를 "운영팀 확인 (확인일)"로 적습니다. 지자체 누리집 링크는 2장 규칙에 따라 붙이지 않습니다.

### 5.6 '우리 지역 입양 지원' 정보 탭 (11-23 요청)

전국 지도와 지역 검색으로 입양 지원을 보여 주는 탭입니다. 비용 지원만이 아니라 교육·입양센터·행사·펫보험 등 **지역의 입양 지원 전체**를 보여 줍니다.

```
[우리 지역 입양 지원]
 ┌───────────────┐  ┌───────────────────────────────┐
 │  전국 지도      │  │ 지역 검색 [ 구리시        🔍 ] │
 │ (시·도 클릭)    │  ├───────────────────────────────┤
 │  색이 진할수록  │  │ 경기도 구리시                   │
 │  지원 종류가 많음│  │  ● 신청할 수 있는 지원 (확정)    │
 │               │  │  ● 조례에 근거가 있는 지원        │
 │               │  │  ● 시·도 지원 (경기도)          │
 └───────────────┘  └───────────────────────────────┘
```

| 동작 | 보여 주는 것 |
|---|---|
| 처음 들어옴 | 전국 지도 + 시·도별 요약 (예: "경기도 · 입양비 지원 8곳 · 펫보험 1곳") |
| 시·도 클릭 | 그 시·도의 시·군·구 목록과 지원 종류 표시(입양비 · 펫보험 · 교육 · 입양센터 · 행사) |
| 지역 검색 · 있음 | 그 지역 카드: ① 신청할 수 있는 지원(5.1 API, 금액·조건·서류·기한·문의처) ② 조례에 근거가 있는 지원(5.4 다, 조례 이름·조문 번호) ③ 그 시·도 지원 |
| 지역 검색 · 없음 | "이 지역은 등록된 입양 지원 정보가 없어요. 시·군·구 동물보호 담당 부서에 물어보세요." + 같은 시·도의 지원 |

정보의 단계 (화면에서 꼭 구분):

| 단계 | 출처 | 화면 표기 |
|---|---|---|
| 신청할 수 있는 지원 | 5.1 공공서비스(혜택) API, 운영팀 보강 표 | 금액·조건을 그대로. "출처: 대한민국 공공서비스(혜택) 정보 · 갱신일" |
| 조례에 근거가 있는 지원 | 5.4 (다) 자치법규 | "조례에 지원할 수 있다는 근거가 있어요. 올해 시행 여부와 금액은 담당 부서에 확인해 주세요." + 조례 이름·조문 번호(링크 없음) |
| 정보 없음 | — | 위 안내 문구 |

- 지도는 지금 화면의 예시 지도(`IllustratedMap`)처럼 그림 지도로 시작합니다. 시·도 경계 그림은 따로 정합니다.
- 01 입양 절차 안내의 6단계 '입양비 지원 신청'에서 이 탭으로 이동합니다.
- 공고 상세의 지원 카드는 같은 데이터를 **보호소 관할 지역 기준**으로 보여 줍니다(5.5).

- 쉬운 요약은 `scripts/guide/build_adoption_support.py`의 `benefit_facts`가 원문에서 글자로 찾아 만듭니다. 원문은 고치지 않고, 못 찾은 칸은 비웁니다. 테스트는 `tests/test_guide_adoption_support.py`에 있습니다(7개).
- 조례 자동 분류(5.4 다)는 화면에 쓰지 않고, **운영팀이 혜택을 더 찾을 지역 목록**으로만 씁니다. 운영팀이 확인한 혜택은 보강 표(5.4 가)로 넣으면 같은 카드로 보입니다.

### 9.6 읽기 쉽게 · 내 위치 · 카카오 (11-23)

- 입양 안내 3페이지의 본문 글씨를 약 5px 키우고 색을 진하게 했습니다(회색 → 짙은 녹색 계열).
- 단계 설명은 문장마다 한 줄씩 끊어 보여 줍니다(좁은 폭에서 두 줄로 접히지 않게).
- **내 위치로 찾기** (우리 지역 입양 혜택 페이지)
  - 브라우저 위치 권한으로 현재 위치를 받아 지도에 파란 점으로 보여 줍니다.
  - 카카오 키가 켜져 있으면 카카오 좌표 → 행정구역 조회로 시·군·구를 찾아 그 지역 혜택을 바로 엽니다(`frontend/src/lib/kakao.ts`).
  - 키가 없거나 조회가 안 되면 **가까운 확인된 혜택 3곳**을 거리 순으로 보여 줍니다(예: 영등포 기준 영등포구 0km · 동작구 4km · 관악구 7km).
  - 위치는 화면에서만 쓰고 저장하지 않습니다.
- **카카오 키 확인 결과 (11-23)**

| 키 | 결과 | 해야 할 일 |
|---|---|---|
| REST (`.env` kakao_rest_api) | 401 `ip mismatched` (이 PC 공인 IP 미등록) | 카카오 개발자 콘솔 › 앱 키 › REST API 키의 허용 IP에 개발 PC·서버 IP 추가 (또는 제한 해제) |
| JavaScript (`.env` kakao_java_api) | 403 `App(RE:봄) disabled OPEN_MAP_AND_LOCAL service` | 앱의 카카오맵 사용 설정 켜기 + 플랫폼 › Web 사이트 도메인에 `http://localhost:3000`(과 배포 주소) 등록 |

- 설정 뒤 `frontend/.env.local`에 `NEXT_PUBLIC_KAKAO_JS_KEY=`(JavaScript 키)를 넣고 개발 서버를 다시 켜면 시·군·구 자동 찾기가 동작합니다.
- 지도 화면은 지금처럼 OpenStreetMap을 쓰고, 카카오 지도 품질을 본 뒤 바꿀지 정합니다. 바꿀 때는 `components/map/KoreaMap.tsx`만 바꿉니다.
- 보호센터 페이지의 위치·길찾기는 카카오를 쓸 예정입니다.

### 9.7 카카오 지도 적용 (11-23, 콘솔 설정 뒤 다시 확인)

| 확인 | 결과 |
|---|---|
| JavaScript SDK (`localhost:3000`) | 200, 지도 표시 OK |
| 좌표 → 행정구역 | 구리시 좌표 → "경기도 구리시" |
| 장소 검색 ('구리시 동물보호센터') | OK (남양주시동물보호센터 등) |
| REST API (서버용) | 200 (허용 IP 등록 뒤) |

- 카카오 지도는 한글 지명이 깔끔하고 통합 행정구역(전남광주)도 반영돼 있어, 키가 있으면 **카카오 지도를 기본**으로 씁니다.
- 키가 없거나 SDK를 못 불러오면 OpenStreetMap(Leaflet)으로 자동으로 돌아갑니다. 두 지도는 `components/map/KoreaMap.tsx` 안의 엔진 두 개(`kakaoEngine`, `leafletEngine`)로 같은 점·내 위치·이동을 그립니다.
- 키 위치: 로컬은 `frontend/.env.local`의 `NEXT_PUBLIC_KAKAO_JS_KEY`(git 에 올리지 않음). 배포 때는 빌드 환경 변수로 넣고, 배포 도메인을 카카오 Web 사이트 도메인에 등록해야 합니다.
- **내 위치로 찾기**는 카카오 좌표 → 행정구역으로 시·군·구를 바로 엽니다(확인: 구리시 → "경기도 구리시", 확인된 혜택 없음 안내).
- 보호센터 페이지의 위치·길찾기에 같은 `lib/kakao.ts`를 씁니다(REST 키는 서버에서만).
