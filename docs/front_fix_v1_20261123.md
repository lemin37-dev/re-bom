## 2. 품종 정보(크기)

### 2.1 보여 주는 내용

- 공고 상세 '외형 정보'에서 공고 체중·색상 태그 아래에 보여 줍니다.
- 표기 예:

| 경우 | 화면 |
|---|---|
| 한 크기 안에 있음 | `14~23kg, 중형` |
| 크기 경계에 걸침 | `4.5~11kg, 소형~중형` |
| 상한만 있음 | `5kg 이하, 소형` |

- 아래 작은 글씨: "품종의 대표 몸무게예요. 이 아이의 크기는 위 공고 체중 기준이에요 · 출처 FCI · Dog API"
- 키는 쓰지 않습니다. 몸무게와 크기만 씁니다.

### 2.2 크기가 여러 가지인 품종

푸들·슈나우저·닥스훈트는 크기별로 줄을 나눕니다.

| 공고 품종명 | 보여 주는 줄 |
|---|---|
| 크기가 적힌 이름 (예: `미디엄 푸들`) | 그 줄 하나만, 이름 없이 |
| 계열 이름 (예: `푸들`) | 모든 줄, 줄마다 이름을 붙여서 |

| 계열 | 줄 |
|---|---|
| 푸들 | 토이 1.8~2.7kg · 미니어쳐 4.5~6.8kg · 미디엄 6.9~17.9kg(팀 결정) · 스탠다드 18~32kg |
| 슈나우저 | 미니어쳐 4~9kg · 스탠다드 14~23kg · 자이언트 25~47kg |
| 닥스훈트 | 스탠다드 7~14.5kg · 미니어쳐 5kg 이하 · 래빗(몸무게 자료 없음) |

### 2.3 데이터 범위와 출처

- 3년 치 공고에 **한 번이라도 나온 품종을 모두** 넣었습니다(`breed_candidates_3y.json` 62종). 61계열, 68줄입니다.
- 공고 품종명 표기 71가지를 하나씩 확인했습니다. 69가지는 화면에 나오고, 2가지는 숨깁니다(2.4).
- 출처 순서: **FCI 품종 표준 → 국가유산청 → Dog API**. 미국애견협회(AKC) 자료는 쓰지 않습니다.
- FCI와 Dog API 값이 모두 있으면 범위를 합칩니다(작은 하한 ~ 큰 상한).
- 팀이 정한 값:
  - 미디엄 푸들 6.9~17.9kg
  - 퍼그 6~8.1kg
- 품종별 값과 원문 근거는 `docs/breed_size_table_20261123.md`에 있습니다.

### 2.4 숨기는 경우

| 경우 | 예 |
|---|---|
| 믹스견, 표에 없는 품종 | `믹스견`, `핏불테리어 믹스견`, `기타` |
| 몸무게 자료가 없는 품종 | 래빗 닥스훈트, 미텔 스피츠 |

### 2.5 품종명 맞추기

- 공고 품종명과 표의 이름을 비교할 때 띄어쓰기와 `져/저`·`쳐/처` 표기 차이는 무시합니다.
  - 예: `미니어처 슈나우저` = `미니어쳐 슈나우져`
- 이름이 정확히 같을 때만 맞춥니다. 그래서 `핏불테리어 믹스견`은 `핏불테리어`로 보지 않습니다.

## 3. 공고 정보 · 제목 · 크기 표시

| 자리 | 전 | 후 |
|---|---|---|
| 상세 제목 | `푸들 · 암컷 · 3살 (추정)` | `푸들 · 암컷` |
| 목록 카드 · 지도 목록 제목 | `품종 · 나이` 포함 | `품종 · 성별` |
| 요약 줄 | `3kg · 갈색 · 중성화 확인 필요` | `3kg, 소형 · 갈색 · 중성화 확인 필요` (크기가 있을 때) |
| 외형 태그 | 화면에서 계산한 크기 (8kg / 15kg 경계) | 검색 API `size` 값 (화면에서 계산하지 않음) |
| 공고 정보 | 출생 연도 없음 | `출생 연도 2022년생`, 없으면 `공고에 없음` |

- 나이(N살)와 60일 미만 정보는 화면에 쓰지 않습니다. 출생 연도만으로는 월을 몰라 나이가 틀릴 수 있기 때문입니다.
- 검색 API의 크기 값은 영어(`small` / `medium` / `large`)로 받아 화면에서 `소형` / `중형` / `대형`으로 바꿉니다.

## 5. Silver를 빼고 올리면서 생긴 임시 동작

지금 develop 검색 API는 Silver의 `size`·`birth_year`를 아직 내려주지 않습니다. 그래서 이렇게 동작합니다.

| 항목 | 지금 | Silver 값이 API에 붙으면 |
|---|---|---|
| 크기 태그·요약 줄의 크기 | 숨김 | 자동으로 나옴 (프론트 수정 없음) |
| 출생 연도 | 원문 `ageText`(예: `2022(년생)`)의 연도를 씀 | API `birthYear`를 먼저 씀 |
| 크기 필터 | API 몸무게로 거름. 범위 몸무게(`3~3.5kg`)는 **평균값** 기준 | Silver처럼 **큰 값** 기준이 되면 경계 근처 결과가 맞춰짐 |

- Silver의 크기 경계와 전체 데이터의 크기 다시 만들기는 Silver 담당이 작업합니다. 프론트는 고친 값을 받아 씁니다.
- 개인 브랜치의 예전 커밋(`c5467df`)에 있는 Silver·검색 API 변경은 PR #62에 넣지 않았습니다.
  - `storage/cleaning/weight.py`, `storage/silver/transform_notice.py`
  - `serving/derive.py`, `serving/schemas.py`, `serving/repository.py`와 관련 테스트
